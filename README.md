The project is cricket game made with Unity(C#) and it uses realistic physics and a functional gameplay.

this project was developed for my nea project in college. it allows the user to login or make a account and it works with database to
store user information and it has realistic gameplay typically what u would expect in a cricket game. The ball comes flying at the batsman and 
the player is playing in the pov of the batsman and when the button is pressed the ball goes flying to boundary hitting a four or six runs.

Technologies used were Unity which uses C# and SQL for Database.

1. Realistic Physics
